# Q4 抽取准确率评估

评估标签由 Codex 直接阅读葡语原文预标。正式评估需要葡语双人独立标注并仲裁分歧。两个样本各 30 条，标签与发布结果可独立重算。

标注区分整单未收、部分缺件、送达超期和地址投递异常。正文只有情绪、正面送达评价或仍在等回复但无失联证据时，不推断具体问题。每个类别在同一评价最多计一次。

全量 **22,493** 条的结构、ID 覆盖和数值范围均通过检查。发布的 **2,488** 条证据均是对应葡语正文的连续子串，且通过隐私模式筛查。原文可定位性与语义正确性分开计，后者还需要复核类别、严重度和翻译。

## 独立留出样本

逐条类别集合完全一致 **4/30**。类别微平均精确率 **75.0%**，召回率 **8.8%**，F1 **15.8%**。TP 3，FP 1，FN 31。预测类别中标注未支持的比例 **25.0%**。
