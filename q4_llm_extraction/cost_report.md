# Q4 成本、用量与时长

本地 Qwen2.5-3B Instruct Q4_K_M 由 llama.cpp b12241 在 RTX 4070 Laptop GPU 上推理。数据、权重和推理均在本机处理。本次云端 API 费用为 **$0.00**，单条平均 API 费用也为 **$0.00**。电耗和设备折旧未测量。

| 实测项目 | 结果 |
| --- | ---: |
| 原始评分 1–3 分记录 | 22,754 |
| 按评价 ID 取最新后 | 22,493 |
| 空正文 / 有正文 | 8,207 / 14,286 |

耗时覆盖加载、规则、模型和结果写入，模型服务已启动，数据已下载。任务最多新推理 300 条，代码另设 38 分钟的总时限，给落盘保留余量。100 批的 token 采用服务返回的 usage，包含有 usage 的无效结果。被拒绝、批响应失败及未入选的记录保留基线。复核后扩充了葡语规则，最终有 2,447 条评价包含证据。157 条模型缓存可以离线复用，其中 149 条仍补充了规则未覆盖的类别。

## 单条与三条合批

同一组 6 条复杂正文，分别运行 6 次单条和 2 次三条批请求。两种模式都使用相同的模型和提示词。

| 模式 | 请求 | 输入 token | 输出 token | 实测时间 |
| --- | ---: | ---: | ---: | ---: |
| 逐条 | 6 | 3,063 | 889 | 23.938 秒 |
| 每批三条 | 2 | 1,234 | 840 | 16.047 秒 |

合批减少约 **59.7%** 的输入 token，因为多条评价共享系统提示。两种模式的 API 费用均为零。样本时延受并行推理影响。扩大批次会增加截断、批内漏 ID 和单批回落的影响面，因此保留小批并逐条验证。上述 12 条次对照实验的 token 与时间独立于主运行。
