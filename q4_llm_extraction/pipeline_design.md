# Q4 葡语评价抽取设计

先保留 1–3 分评价中每个评价 ID 最新的一条。空正文和只有“ruim”等泛化情绪的评价直接处理。其余评价按正文去重，把葡语原文切成带字符位置的片段。Qwen 每批读四条，返回情绪、类别、证据起止编号及严重度。语法约束固定行数与编号范围，程序从原文切出证据，保留大小写、重音和原有标点。跨句比较数量或规格时可以引用连续范围。

同一个模型用第二份提示词逐项回答证据是否支持该类别。把通过复核的片段交给本地 Argos 葡英模型，跨句证据按句翻译再拼接。生成结果时还检查引用是否包含类别所需的线索。例如只说买了几件无法证明缺件，提到箱子也无法证明包装损坏。合并已有规则后校验字段、数值范围、引用长度和隐私模式，再输出严格 JSON。

从零重算给分类、复核和翻译设总时限。失败或超时的评价回落到已有结果和规则。常规运行按原文及提示词指纹复用缓存，便于在没有 GPU 的机器重现。置信度用于排序，语义、严重度和译文仍须抽样复核。
