# Q4 葡语评价抽取设计

先按评分选取 1–3 分评价，再按评价 ID 保留该范围内最新一条。空正文进入空问题列表，短句如“ruim”只提供情绪线索。规则只匹配有明确语义的葡语短句，引用原始大小写和重音，并为相应短句提供英文翻译。整单未收归配送，部分缺件单独归类，避免把所有“没收到”当作同一种问题。

对较长且带有未覆盖业务词、多个线索或歧义的评价打优先级。同分用固定哈希排序。把优先项以三条一批送入本地 Qwen。批内短 ID 必须完整回传。JSON Schema 限定字段与类别，程序再检查类型、分数范围、葡语引用、长度和隐私模式。规则证据优先，模型补充经校验的新类别。失败、未入选和超时项保留规则结果。

本地推理设置评价数和总时间上限，默认复用输入及提示词指纹都一致的有效缓存。这样可以先跑完所有数据，再在成本和延迟范围内增量补覆盖。语义分类、严重度和翻译仍需抽样复核，置信度只作为排序信号。
